Apresentação

Este documento descreve a estrutura de dados do sistema PlataformaEnsino, desenvolvido como parte do Projeto Integrado Multidisciplinar (PIM III) do curso de Tecnologia da Informação da Universidade Paulista — UNIP.

O banco de dados foi modelado utilizando a abordagem Code-First do Entity Framework Core com SQL Server, aplicando o padrão Table Per Hierarchy (TPH) para a hierarquia de usuários. Para cada tabela são especificados: nome da coluna, tipo de dado SQL Server, restrições de integridade e descrição semântica do campo.

1 Usuários

1.1 Usuarios

Armazena todos os perfis de usuário do sistema. Implementada com Table Per Hierarchy (TPH).
Entidades: Usuario (abstrata) · Aluno · Professor · Coordenador · Admin
Table Per Hierarchy (TPH): uma única tabela representa toda a hierarquia de herança. O campo TipoUsuario funciona como discriminador e determina o tipo concreto do registro. Colunas exclusivas de um subtipo armazenam NULL para os demais perfis.
